## ⚡ كود سريع للتجربة (Quick Example)

```python
# طباعة رسالة ترحيبية
name = "Rifan"
print(f"Hello, {name}! Welcome to Python. 🐍✨")

# مثال على شرط بسيط
age = 19
if age >= 18:
    print("You are ready to code! 💻")

    🚀 عالم بايثون الساحر (Python Wonderland) 🐍
"لغة البرمجة التي تجمع بين بساطة القراءة وقوة الأداء!" 🌟

🎨 1. لماذا تحب الجميع لغة بايثون؟
بسيطة وسهلة: تشبه اللغة الإنجليزية الطبيعية، مما يجعل كتابة الكود ممتعة وغير معقدة.

متعددة الاستخدامات: تُستخدم في الذكاء الاصطناعي، تحليل البيانات (Data Science)، تطوير الويب، وصناعة الألعاب.

مجتمعات ضخمة: ملايين المبرمجين حول العالم يدعمونها ويتشاركون المكتبات الأكواد الجاهزة.
⚡ 2. أساسيات سريعة (Cheat Sheet)
🖨️ طباعة النصوص (Print)
لطباعة أي شيء على الشاشة لتراه بوضوح:

Python
print("Hello, World!")

📦 المتغيرات وأنواع البيانات (Variables)
حفظ المعلومات بكل سهولة بدون الحاجة لتعريف نوع البيانات مسبقاً:

Python
name = "Rifan"      # نص (String)
age = 19           # رقم صحيح (Integer)
is_active = True   # قيمة منطقية (Boolean)

🔀 الجمل الشرطية (If Conditions)
لتوجيه البرنامج بناءً على الشروط:

Python
if age >= 18:
    print("Welcome to the adult world! 🎓")
else:
    print("Keep learning and growing! 🌱")

    🔁 الحلقات التكرارية (For Loops)
لتكرار المهام بدلاً من إعادتها يدوياً:

Python
for i in range(5):
    print(f"Loop count: {i}")

    💡 3. لمسات ذكية (Pro Tips)
القراءة والنظافة: بايثون تعتمد على المسافات البادئة (Indentation) بدلاً من الأقواس، مما يجعل شكل الكود مرتباً وأنيقاً تلقائياً.

مكتبات خوررافية: مثل Pandas و NumPy اللي تخلي التعامل مع البيانات وتحليلها متعة بحد ذاته.
